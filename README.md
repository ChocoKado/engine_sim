# HYPERENGINE

可在電腦與手機操作的引擎模擬駕駛座。首頁是雙圓轉速／車速儀表、即時引擎動畫、金屬踏板與檔位操作；完整 3D 與機械剖面可以切換。底部分頁提供駕駛、改裝、聲浪、性能與設定。20 款代表引擎使用原廠公布的排氣量、功率／扭力峰值與傳動資料建立基準，包含 Honda VTEC、水平對臥及 Mazda 雙轉子。

目前共 **29 個引擎預設**。新增 RZ350 二行程、V4、VR6、W12、787B 四轉子、自然進氣 V16 及雙排十八缸；M250 改為真正分開 N1／N2 的雙軸渦輪軸，搭配兩速示範負載。另有冷車／暖機、過熱降功率、散熱水箱改裝、聆聽位置、J85 啟動異常，以及設定保存、錄製曲線疊圖與 CSV／JSON 匯出。[操作、原廠來源與估算範圍](docs/engine-expansion-suite.md)

**J85 渦輪噴射測試台**使用獨立的 N1／推力模型，顯示核心轉速百分比、kN、EGT、燃油流量與後燃器，沒有汽車檔位或排氣量改裝。聲音由連續燃燒與轉子階次產生，與 3D／剖面共用運轉狀態。[噴射模型邊界](docs/turbojet-test-bench.md)

扭力曲線中間點、風阻、慣量及改裝效果仍是估算；聲浪是程序合成，並非代表車錄音。資料來源與邊界見 [實車基準](docs/engine-reference.md)、[20 款齒比查核](docs/gearing-audit.md)，使用者 1～20 項需求的實作及驗證狀態見 [修復對照](docs/repair-status.md)。

六類新增零件為進氣、排氣頭段、凸輪、飛輪、中冷器及機械增壓皮帶輪；作用、取捨、架構相容性與研究來源見 [車庫改裝說明](docs/garage-modifications.md)。3D 為各架構的程序組裝示意，並非二十台代表實車的精確原廠 CAD。

## 操作

- **駕駛首頁**：上方選引擎，轉速與時速各有指針及數位讀值。引擎動畫與油門／煞車維持共同可見；按住踏板、使用持續油門滑桿，或鍵盤駕駛。綠色按鈕啟動，運轉中可熄火。下方五分頁切換功能，沒有模擬貨幣、解鎖限制或廣告加倍。
- **噴射測試台**：選「J85 渦輪噴射測試台」，啟動後等待起轉。油門增加 N1 與乾推力；勾選「後燃器」後，接近全油門且 N1 足夠高才逐漸接通，增加推力與噴流聲，噴嘴同步張開。額定乾／後燃推力約 15.50／22.24 kN；後燃溫度在渦輪下游另列，不冒充 EGT。收油仍有怠速燃燒，按 STOP 切燃油後轉子繼續滑轉。「推力」分頁可看詳細讀值，切回車款會恢復原本的車輛控制。程序聲浪與中間工況屬工程估算。
- **改裝**：選零件，停車且熄火後才能安裝硬體。按「查看安裝位置」聚焦零件，拖曳旋轉、滾輪／雙指縮放；進氣與凸輪檢查蓋可開啟，飛輪由後端開窗觀察。切換車款恢復原廠零件，切換增壓型式清掉不相容零件。設定與聲浪分頁保留既有控制。
- **改裝取捨**：輕量飛輪只減少飛輪慣量、不加馬力；凸輪／頭段偏重高轉並保留低轉取捨；進氣連動充填及聲音；中冷器降低溫度但增加充氣容積；TVS 皮帶輪增速 ×1.10 同時提高供氣、轉子聲與耗功。SC 壓力滑桿表示原廠皮帶比的基準，裝上增速輪後實際工作點會改變。零件狀態會保存於性能成績，改設定取消未完成測試。
- `X` 啟動／熄火、`W` 油門、`S` 煞車、`E` 升檔、`Q` 降檔。鍵位可在畫面內自訂，也可按住油門／煞車按鈕，或使用持續油門滑桿。
- **AT**：選 `D` 後自動換檔；大油門比較相同車速下相鄰兩檔的可用輪上牽引力，並在限轉削減出力前安全升檔，低油門保留經濟策略及換檔遲滯。起步包含液力扭力轉換器及鎖定接合。**AMT**：使用者決定換檔時機，由系統控制離合器；不需要離合器踏板。
- 前進檔數依代表車決定。Ferrari 458、Aventador、Chiron 有 7 檔，其餘代表車為 6 檔。機車與星型示範不提供倒檔。高速切換 P／倒檔及降檔超轉會受到保護。
- 各檔保留原廠資料；停車且沒有正在換檔時，可調 **終傳倍率 0.75～1.25**，換車恢復原廠 1.00。倍率增大縮短齒比、提高同轉速牽引力並降低紅線輪速；倍率減小則相反，仍可能受功率／風阻限制。畫面列出每檔理論輪速與升檔接合 RPM，並提示抓地、限轉或功率限制；理論輪速不是保證可達尾速。
- 換檔有明確的扭力／點火切斷，再依齒比、輪速及轉動慣量同步接合。AT 與 AMT 的切斷及接合不同；低油門也不會每次都產生全油門式爆鳴。
- 持續全油門碰紅線時，限轉器只在上限前 100～300 RPM 的範圍漸進削減出力，到上限則完整切斷燃燒；降回範圍外立即恢復。保留約 18 Hz 斷油聲，不再維持固定長時間切斷造成最高檔反覆減速、重爬。最高檔若受功率／風阻限制，仍可能達不到紅線。
- **ECU** 可選柔和限轉、賽車硬切或逐缸切斷，並調整 8～32 Hz 節奏與聲浪深度。AMT 固定檔位或空檔較容易聽到限轉；AT 會在可升檔時先換檔。三種模式都保留窄範圍平均出力調節，避免最高檔慢慢掉到 7,000 RPM 再重爬。
- **VTEC**：選 F20C／K20A 後可開關高凸輪並調整切換點。高轉及足夠負載才接合，有回落遲滯；HUD 顯示 LOW／HIGH／OFF。升程、作用角、高轉扭力及進氣聲會改變。K20A 原廠切換點 5,800 RPM，F20C 的 6,000 RPM 為估算；原廠峰值已含 VTEC，不重複增加馬力。
- **Boxer／Rotary**：新增 EJ257、992.2 GT3 與 RX-8 RENESIS。水平對臥使用相反曲柄銷與左右排氣路徑；轉子有專屬殼體、偏心軸與三腔動畫，轉子速度為輸出軸的 1/3，雙轉子每輸出軸一轉燃燒兩次。
- **轉子怠速聲浪**：選 RX-8 後可在聲浪設定切換「原廠 RENESIS」與「改裝 Brap」。原廠保留規律燃燒脈衝；Brap 有明顯強弱段落，隨轉速與負載增加逐漸收斂。這是改裝音效示意，只改聲音，不宣稱模擬了橋式埠的扭力或換氣；排氣管仍影響音色與音量。
- 真正外部負載使轉速低於估算的最低維持燃燒轉速時，模型標記失速並由慣性停止；介面顯示「引擎失速 · 重新發動」，聲音及加速測試同步停止。按一次啟動即可重新發動；踩油門本身不會自動啟動引擎。
- 怠速控制下的淨扭力可平衡為零，離合器起步仍依當前進氣與負載下的可用扭力餘量估算最低咬合，避免輕油門 AMT 困在怠速。真正傳遞量仍受實際淨扭力、曲軸慣性與抓地限制。
- **Turbo** 可切換小／大渦輪；小渦輪較早建立增壓，大渦輪較晚起壓。先在負載下建立增壓，再收油門，才會出現所選 BOV 放氣或無洩壓閥 Flutter 反串流聲。
- **Roots／TVS Supercharger** 由曲軸驅動，低轉即可增壓，旁通控制部分負載，並扣除驅動耗功。尖叫音隨實際轉子轉速升降；不使用 Turbo 的 BOV／Flutter。
- CP4／RENESIS 在 SC 3 bar 的低轉負載與再起步問題已重現並修正：近停轉供氣及壓力可回落，低轉旁通保留可用扭力，傳動不耗盡曲軸慣性能量。3 bar 是研究用外插設定，超過所參考 TVS 的公開工作範圍，不代表原廠機械增壓實車可用配置。
- 換引擎時會套用該代表車的排氣量、紅線、車重、檔位與原廠進氣型式。Supra、GT-R、Chiron 的原廠功率已包含增壓，模型不會再重複加一次原廠增壓倍率。
- 排氣管同時影響估算輸出、音色及回火／火焰強度。OEM 預設不噴火，改裝排氣依管型產生不同的收油、換檔與斷油事件；音量滑桿只改聲音，不改事件與動畫。
- 0.05×～1.0× 慢動作只調整機械動畫，轉速、車速及聲音持續以即時速度運作。
- 主畫面為完整 3D 組裝，支援 Inline、V、W16、Boxer、Radial、Rotary，增壓及已安裝零件具有不同幾何。機械剖面保留共同曲軸／曲軸箱與全部汽缸，另可放大單缸／單轉子。CP4 物理、聲音及剖面共用 1–3–2–4 與 270–180–90–180° 節奏。
- 手機固定保留引擎動畫、RPM／時速／檔位 HUD 及踏板，使操作時可同屏閱讀；橫向短螢幕把動畫與踏板排在同一列。設定面板獨立捲動。數位時速不會被轉速指針遮住。
- **加速測試**：啟動引擎、選 D 或 AMT 前進檔，再按「回到起點並準備」。它會重設車速與油門，準備時自動煞住，踩油門後放開並開始計時。量測 0–100、100–200 km/h 及 402.336 m；也可選 100–200 滾動測試。可提前結束保存已完成項目，最近 8 次成績連同改裝設定存於本機瀏覽器，並用時間差與車速曲線比較。測試中改設定、熄火或選 N／R 會取消。

AT／AMT 是網站的操作模式，不表示每款代表實車都有原廠液力 AT。七缸星型採 **Rotec R2800**；網站上的車速與 6 檔是實驗地面負載，並非螺旋槳或飛行模型。

## 模擬方式

物理使用固定 240 Hz 步進。引擎依扭力曲線、節氣門／進氣充填及曲軸慣量升降轉；傳動以容量受限的離合器扭力耦合曲軸與車輪。齒比包含一次減速與終傳，車重包含 75 kg 駕駛。輪胎抓地限制、滾阻、風阻與反向負載共同決定加速及尾速。

Turbo 使用排氣能量、轉子能量及有限進氣容積建立增壓遲滯；BOV／Flutter 的事件依收油前壓力與轉子狀態產生。Roots／TVS 使用曲軸傳動、旁通及壓縮耗功。壓縮空氣的升溫與冷卻會影響密度；此模型不是完整壓縮機效率圖或 ECU 控制器。

聲音由 AudioWorklet 逐取樣產生連續燃燒壓力脈衝：四行程依 720° 點火週期，RENESIS 依 360° 輸出軸事件週期。加上排氣反射、進氣氣流、機械階次及負載飽和。十字曲軸 V8 與 Boxer 依左右汽缸列的排氣路徑區分音色。換檔時削弱燃燒脈衝，機械運轉、泵氣及排氣尾音持續，不把整個輸出歸零。VTEC 增加高轉進氣共鳴，ECU 切斷跟隨所選模式、頻率與實際切斷比例。Web Audio 環境不支援 Worklet 時保留合成備援。

## 動態量測與參考

```sh
node scripts/measure-dynamics.js
```

量測腳本將日期、條件及結果寫入 `reports/dynamics-current.json`：20 引擎 × 2 傳動 × 5 配置（原廠、NA、小 Turbo、大 Turbo、Roots／TVS），共 200 組。使用 OEM 排氣，全油門 20 秒後煞車 20 秒；改裝增壓統一 1.0 bar，AT 自動換檔，AMT 由測試駕駛在 94% 紅線主動升檔。腳本檢查有限數值、抓地限制、齒比鎖定、起步及煞停回怠速。AMT 模式本身仍不會自動換檔。

這些是模型量測，沒有模擬原廠 launch control 或每台 ECU。舊 `reports/dynamics-before.json` 使用不同基準與測量條件，不能直接當作同條件性能提升，亦不能當成實車成績。

六項硬體的同條件比較可用以下指令重新產生：

```sh
node scripts/measure-modifications.js
```

腳本比較 K20A、CP4、十字曲軸 V8、RENESIS，分別使用 NA、Turbo、Roots／TVS；各組包括原廠、單項相容改裝及全部相容零件，共 **81 組**，寫入 `reports/modifications-current.json`。維持同車原廠排氣量、車重、齒比與 OEM 排氣，使用 AT；Turbo／Roots／TVS 的增壓基準為 1.0 bar，SC 基準保留原廠皮帶倍率，增速輪則改變實際工作點。記錄空檔怠速升至 5,000 RPM、從首次跨過 5,000 RPM 收油降至 1,500 RPM、0–100 km/h 及全油門 20 秒車速，並檢查數值有限與引擎持續點火。這是模型比較，不保證每個零件都改善所有項目，亦不是實車改裝成績。

畫面內性能計時使用每個 240 Hz 物理步的未取整速度、累計距離及模擬時間，在門檻間插值；不按畫面幀率計時，也不加 1 foot rollout。¼ mile 的「終點速度」是通過終點瞬間的速度，不是競賽計時設備的末段平均 trap speed。低性能配置若 120 秒仍未完成，會保存已完成項目。
