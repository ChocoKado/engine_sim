# engine_sim — 原始規劃包

本機啟動、測試與部署流程見 [README](README.md)，目前里程碑見 [開發進度](docs/PROGRESS.md)。

## 原始規劃包的檔案

把本壓縮檔中的檔案與資料夾合併到既有 GitHub 專案 **`engine_sim` 的根目錄**：

```text
engine_sim/
├─ AGENTS.md                 # Codex 工作規範／節省額度
├─ CODEX_PROMPT.md           # 可直接給 Codex 的開場指令
├─ PLAN.md                   # 專案完整計畫書
├─ README_先讀我.md
├─ data/
│  └─ MODEL_CATALOG.csv      # 14 筆車款清單及資料驗證狀態
└─ docs/
   ├─ PHYSICS_AUDIO_SPEC.md  # 變速、引擎動態、聲音及改裝規格
   ├─ MOBILE_QA.md           # 手機互動與驗收測試
   ├─ SOURCES.md             # 官方來源、資料可信度及未查證項目
   ├─ ROADMAP.md             # 小批次里程碑
   └─ PROGRESS.md            # Codex 每次完成後更新
```

如原本專案已經有 `AGENTS.md`、`PLAN.md` 或其他同名檔，**請先合併規則，不要覆蓋原有內容**。

## 如何啟動里程碑

1. 將文件放進 `engine_sim` 專案根目錄，或先把整個 ZIP 上傳 Codex 的工作環境。
2. 讓 Codex 打開 `engine_sim` 儲存庫。
3. 貼上 `CODEX_PROMPT.md` 的內容（也可直接說：**「請閱讀 CODEX_PROMPT.md 並執行 M0」**）。
4. 每次只核准一個小里程碑，依 `docs/PROGRESS.md` 接續。
5. GitHub 版本管理、Vercel 部署依實際權限設定；若沒有登入／授權，Codex 不得虛稱已部署。

## 你指定的核心需求

- **現在做：** Yamaha **R15、R3**；以真實引擎結構、聲浪、騎乘互動為主。
- **未來 Yamaha：** R6、R7、R9、R1（加上 R15/R3 共 6 款）。
- **未來 Kawasaki：** ZX-25R、ZX-4R、ZX-6R **599／636 分開建檔**、ZX-10R、ZX-14R、Ninja H2、Ninja H2R。
- 六速 **1–N–2–3–4–5–6**，手動升降檔撥片及自動換檔；畫面無須離合器操作，但物理模型須有內部離合／傳動耦合概念。
- 制動、車速、輪速、轉速相互連動；手動高速連續退檔可觸發**機械超轉**，不能只用轉速限制器把超轉消除；自排預設有保護邏輯。
- **聲音是第一級功能：** 油門、RPM、負載、換檔瞬態、退檔補油、引擎煞車、排氣改裝要與物理狀態一致。H2/H2R 後續要有**機械增壓器音層**，不可混成普通渦輪增壓音。
- **手機網頁是主要測試環境：** 觸控多指、直橫屏、iOS Safari、Android Chrome、音效解鎖、效能及安全音量。

## 重要觀念

**真實機械幾何 ≠ 經實測驗證的動力模型 ≠ 原車錄製音檔。** 只有來源充分時才能稱為原廠規格或實錄；其他一律標示「近似」「示意」「待驗證」。

本包沒有任何付費音檔、車廠專利模型或未授權素材。後續如要高度擬真的聲浪，須另行取得可合法使用、車型／年式／排氣規格匹配的多工況錄音，並實施 A/B 盲測與量化比對。
