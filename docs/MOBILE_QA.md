# engine_sim — 手機優先 UI／QA 驗收規格

## 1. 目標設備與瀏覽器

優先實機：iPhone Safari（iOS／iPadOS Safari）與 Android Chrome；次要桌面 Chrome/Edge。不同 iPhone 瀏海/動態島與 Android 底部手勢條均需考慮 `safe-area-inset`。使用 HTTPS 的 Vercel Preview/Production 網址測試，不能僅用桌面視窗縮小當作手機驗收。

## 2. 互動區塊

- **直式**：上方車型/模式及 RPM、速度、檔位；中段可切換 3D／教學；下方固定或清楚可見的 **油門（右手長按）／煞車（左手長按）／+／−**，點擊區域至少約 44×44 CSS px，排版避免誤觸。
- **直式短螢幕**：踏板高 120–160 CSS px，換檔鍵至少 48 CSS px。短螢幕將轉速、車速及檔位並排，捲到儀表後應能在同一畫面操作兩個踏板。
- **橫式**：3D／儀表與控制並排，可見操作狀態；避免頁面捲動與方向切換造成觸控中斷後油門卡住。
- **多指**：同時按油門與煞車，或以另一指換檔、操作 3D 視角。每個踏板用 Pointer Events 與 pointer capture 獨立接收開度。
- **觸控安全**：拖曳超過踏板上緣或下緣時保持相應端點。放手、觸控取消或失去 capture 時清除該手指；失焦、進入背景或旋轉裝置時，兩個踏板都回 0%。
- **觸覺與可及性**：有文字檔位和錯誤訊息；顏色以外提供符號；音效關閉時仍能看出 RPM、檔位、模式與超轉。

## 3. 音訊／裝置切換

- 首次啟動引擎由使用者明確點擊/觸控觸發 AudioContext；若瀏覽器阻止，UI 顯示「點擊啟用音效」。
- 來電、背景分頁、螢幕鎖定、耳機插拔/藍牙切換後重新獲取 AudioContext 狀態；恢復時要平滑淡入、不能爆音。
- 預設安全音量、靜音一鍵可用；內建軟限制器防尖銳聲與突然的音量峰值。
- 速度／RPM／排氣修改等狀態更新不能使聲音和 3D 失去同步。

## 4. 3D／效能

- 手機預設中低特效（較低像素比、合理幾何數、少陰影），提供畫質選項；桌機可提高細節。
- 3D 降幀時，物理計算與音訊事件不應被渲染 FPS 直接拖慢；避免用 `requestAnimationFrame` 當唯一物理時鐘。
- 發熱與長時間使用需觀察流暢度；若高負載，畫質可以降級但物理狀態不可亂跳。
- 不要無限放大音檔/模型體積；首屏載入可逐步顯示骨架、進度與錯誤重試。

## 5. 真機驗收案例

| 編號 | 操作 | 預期結果 |
|---|---|---|
| M-QA-01 | 直式進入首頁並選 R15/R3 | 元件無水平溢出、車型/模式顯示正確 |
| M-QA-02 | 手指按住油門，另一指按升檔 | 油門不中斷、檔位正常切換、RPM/聲浪依物理變化 |
| M-QA-03 | 同時按煞車及連續降檔 | 車速/輪速/RPM耦合；可觸發合理的機械超轉情境 |
| M-QA-04 | 拖出踏板後放手、來電、切換分頁 | 油門及煞車回 0%，音訊正常暫停或恢復 |
| M-QA-05 | MT ↔ AT 模式切換 | 不產生無法解釋的瞬間換檔；AT 不主動超轉退檔 |
| M-QA-06 | 直式 ↔ 橫式 | 內容無遮擋，油門不會卡住，音訊無爆音 |
| M-QA-07 | 3D 旋轉、縮放、開啟剖面 | 不影響油門/聲音物理時鐘；有性能降級策略 |
| M-QA-08 | 靜音 → 音效啟用 → 背景 → 返回 | 能重啟音訊、音量漸變，不會突然滿音量 |
| M-QA-09 | 引擎運轉時切換排氣／進氣音色 | 變更共鳴，連續保留聲音、檔位及油門位置 |
| M-QA-10 | H2/H2R 高轉與減速 | 機械增壓專用音層可獨立觀察、與 RPM/增壓器轉速相關 |
| M-QA-11 | 切品牌，橫滑找到車款，切走再切回 | 記住車款，橫滑不影響整頁寬度，車款版本與規格連結同步 |
| M-QA-12 | 比較直列四缸、RSV4 與 Panigale V2／V4 的 3D | 缸列、汽缸數與點火節奏對應選車，剖面切換正常 |

| M-QA-14 | Kawasaki 的「全部車款」直接選 H2 與 H2R | 兩款都可直接選到；H2 的解除限速保留原 RPM 斷油 |
| M-QA-15 | 中高轉反覆收油 | 回火偶發且延遲不同，持續加油與怠速無回火 |
| M-QA-16 | 中高轉帶油反覆升檔 | 斷扭時偶發單次短響，背景聲浪與接合後升轉保持連續 |
| M-QA-17 | 切換機車、汽車、飛機與航天 | 操作區切換，機車與汽車各自保留車款，離開時停止舊音訊 |
| M-QA-18 | GR86／RX-8 開剖面，飛機改變輸出或負載 | 水平對臥活塞、雙轉子及航空軸系隨共享狀態變化 |

| M-QA-21 | Toyota 品牌切換 GR Supra／A80，匯入短定轉錄音並啟用 A/B | 下拉只列所選品牌，錄音在本機解碼，切換時 RPM 連續 |
| M-QA-22 | Cadillac 出站後減速進站，煞停再出站 | 限速跟隨區域，暖度及電量保留 |
| M-QA-23 | 道路引擎施以慢速，再看 Falcon 9 兩級台架 | 汽缸與氣流可辨識，一級關機、分離、二級點火順序合理 |
