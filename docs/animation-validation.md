# 引擎剖切動畫的機構與畫面驗證

查核日期：2026-10-03。涵蓋目前全部 20 種配置，包含 Inline、V、W16、Boxer、七缸 Radial 與雙轉子 Rotary。主畫面使用可辨認整台機構的二維剖切；單缸／單轉子模式用來放大觀察機械運動。

## 機構資料與修正

| 架構 | 修正內容與驗證依據 |
| --- | --- |
| Inline／CP4 | 汽缸沿同一曲軸軸線排列，加上連續汽缸頭、曲軸箱及軸線。各缸保留自己的曲柄相位，CP4 不會被畫成四顆同步升降的活塞。Yamaha 說明 crossplane 相鄰曲柄相差四分之一轉，並公開 R1 的不等間隔點火節奏。[Yamaha R1 原廠說明](https://global.yamaha-motor.com/news/2008/0909/yzf-r1.html)、[2017 R1 原廠資料](https://cdn2.yamaha-motor.eu/prod/product-assets/2017/YZF1000R1/Factsheets/2017-YZF1000R1_en.pdf) |
| V | 兩缸列以設定夾角向共同曲軸箱傾斜，沿同一軸線排列。所有 V8／V10／V12 汽缸均繪製，不再裁成最多六缸或以獨立單缸卡片代替全機構。 |
| W16 | 修正四列角度為 −52.5°、−37.5°、37.5°、52.5°，兩個窄角組各相差 15°、組中心相差 90°；每組有連續汽缸頭，四列共享曲軸軸線。原來以 90° 當作內部窄角會產生重合或水平汽缸。[Bugatti W16 原廠布局說明](https://newsroom.bugatti.com/en/press-releases/15-years-of-bugatti-veyron-how-it-all-began) |
| Boxer | 對向汽缸水平排列，對側活塞同時往內／外運動，兩側具有相反而獨立的曲柄銷。加入共同中央曲軸箱，單缸放大仍維持水平視角。這與兩個連桿共銷的 180° V 型不同。[Subaru Boxer 原廠說明](https://www.subaru.co.za/tech/boxer-engines-vs-inline-engines/) |
| Radial | 中央主連桿的大端及其副連桿樞軸為同一剛性組件；每根副連桿長度固定，活塞銷沿各缸軸線移動。修正舊圖副連桿長度變動、配重角度、放大單缸失去中央連接，以及點火與實際 TDC 不一致。FAA 說明副連桿鉸接於主連桿法蘭，樞軸軌跡及各缸活塞行程相位並不完全相同。[FAA Powerplant Handbook 第 1 章，Master and Articulated Rod Assembly](https://www.faa.gov/sites/faa.gov/files/03_amtp_ch1.pdf) |
| Rotary | 使用外旋輪線殼體、偏心軸及三個頂點連續貼合殼體的轉子幾何；轉子每轉一圈，輸出軸轉三圈。轉子三面改為保守的凸曲面，避免直邊正三角形的失真外觀；腔室色區沿相同曲面閉合。修正機構與吸氣／壓縮／燃燒／排氣顏色相位的偏移，三個面各自追蹤，雙轉子保留各自相位。Mazda 技報說明基本機構及轉子速度為軸速三分之一。[Mazda 2003 技報，Rotary Engine Structure and History，Fig. 4／5](https://www.mazda.com/content/dam/mazda/corporate/mazda-com/ja/pdf/innovation/monozukuri/technology/tech-review/2003/2003_no001.pdf) |

活塞式剖面共用有限長連桿解，不再以單純正弦位置代替連桿幾何。完整 720° 掃描確認連桿長度固定、活塞行程連續，以及低／高凸輪切換時，示意氣門不穿過活塞。燃燒區下緣跟隨實際活塞冠面，細節隨縮放比例同步縮小，避免窄幅畫面出現負尺寸或被放大的火焰。火星塞電弧保留在燃燒室附近，不再以未轉換的局部座標把粒子畫到畫布左上角。停止或切斷燃燒時不會留下靜止火球。

## 動畫與物理共源

CP4 原始資料混用了「直接相加的行程偏移」與「絕對點火時間」，並將實體 2／3 缸的時間順序對調。現在以實體汽缸順序存放 `[0, 450, 270, 540]`，標記 `firingAngleKind: 'absolute'`，並以 `wrap(crankAngle - firingAngle + 360)` 同時計算物理和畫面行程。結果是 1–3–2–4 點火、270–180–90–180° 間隔，且點火時活塞位於壓縮 TDC；聲音採相同絕對事件。Yamaha 官方 M1 說明公開由 1–2–4–3 改為 1–3–2–4 的 crossplane 點火順序。[Yamaha M1 機構說明](https://global.yamaha-motor.com/jp/showroom/cp/exhibition/archives/2007_1/machine/2004/)

`src/physics/RadialMechanics.js` 同時供 EngineModel 和 EngineRenderer 使用。`radialFiringAngles()` 回傳各缸**實際壓縮 TDC 的絕對曲軸角**，並保持 1–3–5–7–2–4–6 順序；它不是可直接相加的缸相位。各缸四行程相位為 `wrap(crankAngle - firingAngle + 360)`。物理活塞行程由同一主副連桿幾何的最大／最小距離正規化，避免視覺已到 TDC、壓力卻仍在其他行程。

`src/physics/RotaryMechanics.js` 提供轉子／殼體幾何和三腔狀態。示意四個行程各占 270° 軸角，每個轉子面完成一個循環需要 1080° 軸角。幾何零點經 90° 校準，使相位 0°／540° 對應腔室最小體積，270°／810° 對應最大體積。腔室體積採連續的曲線而非四段直線；物理壓力狀態與畫面顏色使用相同相位 helper。

`rotaryRotorFacePoint()` 提供三個頂點之間的凸曲面點。R70／偏心量 11 的既有殼體採最大弓高 10 的二次曲線，保留頂點接觸而且不穿出殼體；完整 Reuleaux 三角形不能直接套入這組尺寸。測試以殼體極座標的獨立反解，逐軸角 1°、每面 40 點掃描完整 1080°。曲面扣除的面積與轉角無關，因此腔室的正規化行程與壓力相位保持一致；這個輪廓仍是示意，並非原廠轉子曲面設計資料。

固定火星塞以 x≈±13 的實際上側殼體邊界及法向安裝。陶瓷和金屬本體位於殼體外側，電極端相對內壁退縮 0.8 示意單位，避免頂點密封片掃過時撞入電極。完整 1080° 掃描另以轉子曲面／頂點到實際繪出的固定電極矩形的距離驗證，保持大於 0.7 單位淨距。

1.0× 動畫直接使用物理曲軸角；慢動作只改變畫面時鐘，音效與道路動力仍以即時轉速運轉。切換引擎時會重設畫面相位，避免把上一種架構的 720°／1080° 時鐘帶到新引擎。

## 示意的範圍

這是方便看清運作的二維剖切，不是各代表車款的三維 CAD、鑄件工程圖或 CFD。曲軸箱、汽缸頭、視角錯位、缸距、連桿尺寸與氣門淨距採用示意比例。V／W 圖保留缸列夾角與共用曲軸軸線，但沒有宣稱還原每款原廠共銷、分裂銷、主軸承、冷卻水套或凸輪傳動的完整三維結構。星型副連桿樞軸採等半徑示意；實際引擎可用不等樞軸位置及點火凸輪補償其相位差。Rotary 的腔室體積、壓力和火焰形狀亦為模型估算。

手機全機構模式優先保留所有汽缸與其相對布局，精簡文字。W16 等多缸在 180 × 110 時會較小，可切換單缸／單轉子詳看。慢動作、清爽模式與放大視角可以組合使用。

## 自動與瀏覽器驗證

執行 `node --test tests/visuals.test.js tests/mechanical-phase.test.js tests/expansion.test.js`。2026-10-03 本次執行 **36 項全部通過**，其中 visuals 19 項、mechanical-phase 3 項、expansion 14 項。完整專案的最終回歸數量應以 `npm test` 當次結果為準。

測試涵蓋剛性連桿、星型 TDC 及點火順序、Boxer 對向獨立曲柄銷、轉子頂點貼合殼體與 1:3 轉速、曲軸相位與腔室壓力共源、W16 四列角度、高凸輪氣門淨距、所有 20 配置的桌面／手機完整及放大視角，以及多個曲軸角下實際繪圖 API 的有限正尺寸。全景的機械外形也逐點檢查位於可用畫布內；這不能代替人工判斷透視遮擋或外觀易讀性。

啟動專案既有開發伺服器後，開啟 `/tests/visuals-browser.html`：

1. 上方可選引擎、完整／單缸視角、汽缸編號、畫布尺寸及曲軸相位，並播放慢動作。
2. 下方圖集同時呈現全部 20 配置，可比較各架構；點選卡片回到主圖詳看。圖集在全部卡片加入後重新量測尺寸，修正第一張卡片使用暫時全寬造成空白的問題。
3. 切換「燃燒」檢查停止時不殘留火焰；切換「高凸輪」檢查氣門動態。
4. 點「下載目前 PNG」儲存實際 canvas 的主圖，檔名包含引擎、視角及曲軸角，可作審閱附件。該工具只用於 QA，不載入音效及道路模擬。
