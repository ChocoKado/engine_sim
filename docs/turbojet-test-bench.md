# J85-21 噴射測試台

2026-10-15。噴射引擎改為獨立的海平面靜態測試台：用油門、N1 百分比、推力 kN、渦輪出口 EGT 與後燃器操作。沒有輪端變速箱，不把噴射推力換成虛構的曲軸馬力、排氣量或 0–100 成績。

## 查核基準與模型範圍

[NASA TM-81451（J85-21 實驗報告）](https://ntrs.nasa.gov/citations/19800012848) 說明該型是單軸、9 級軸流壓縮機、環形燃燒室與 2 級渦輪，並有後燃器及可變面積噴嘴；報告引用的額定乾推力為 15.5 kN。因此先前「8 級」並不適用這個型號。該報告的 100% 設計轉速資料也提供壓比、流量、燃油與渦輪出口溫度作查核。

[NASA《Pursuit of Power》](https://www.nasa.gov/wp-content/uploads/2015/04/696956main_pursuitpower-ebook.pdf) 記錄 J85-21 為 5,000 lbf 級，換算約 22.24 kN。網站以最大乾推力與後燃額定點校準簡化模型，不宣稱重現特定裝機進氣道、飛行高度或實機試驗的全部工況。

工作原理依 [NASA 渦輪噴射說明](https://www.grc.nasa.gov/www/k-12/UEET/StudentSite/engines.html)、[後燃器](https://www.grc.nasa.gov/www/k-12/airplane/turbab.html) 與 [噴嘴](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/nozzle-design/)：主燃燒室持續供熱；渦輪驅動同軸壓縮機；後燃器位於渦輪下游，增加噴流能量並需要較大的噴嘴面積。EGT 是渦輪出口溫度，後燃器下游的噴嘴溫度另列，不能把兩者混為一個瞬間跳高的讀值。

N1 顯示相對額定轉速的百分比；內部 RPM 僅作一致的聲學／動畫參考，未冒充已查證的原廠絕對軸速。壓縮機工作線、燃油調度、啟動與加減速時間常數、溫度及聲學階次仍為工程估算，並非完整原廠壓縮機圖、啟動控制或 CFD。

## 原問題與修正方向

- 原主音訊處理器將 RPM 截在 24,000，且新增聲型只進入被靜音的備援 oscillator。新的主處理器與備援共用連續燃燒音源；轉子階次跟著核心轉速平滑變化，燃燒／噴流使用連續氣流聲，後燃器另加低頻能量。
- 原噴射引擎被套上六速車輛、活塞扭力、斷油及排氣改裝。測試台使用獨立核心動態與推力；汽車齒比、SC／Turbo、排氣量、凸輪、飛輪與道路測試不適用，模型入口也拒絕這些操作。
- 原完整外觀混入汽車空濾、曲軸附件、飛輪與尾段排氣；入口又被封蓋擋住。航空外觀改用獨立構造、開放入口與尾口、固定導葉與同軸轉子。剖面特寫確實放大燃燒／後燃區，動畫直接讀取同一運轉狀態。
- 主燃燒與後燃器分開判定；收油回怠速仍有主燃燒，關閉燃油後停止燃燒並讓轉子滑轉。慢動作只改畫面，聲音與物理繼續即時運行。

另一款 `gas_turbine` 已在後續擴充改為 M250-C20B 的 N1／N2 雙軸模型，核心與自由動力渦輪獨立，輸出經固定減速後接兩速示範道路負載。道路齒比與車體仍屬估算，不宣稱為 MTT 實車重建；詳見[本次擴充](engine-expansion-suite.md)。以下 870／64 項為噴射測試台首版的歷史驗證，本次擴充另記錄最新結果。

## 驗證

完整 Node 回歸 870／870 通過，包含 13 項噴射物理、35 項音訊／DSP，以及 3D／剖面／雙錶與車輛操作回歸。新增模型不再參加只適用輪端軸輸出的汽車起步、齒比及外掛 SC 矩陣；其推力、啟動、後燃、關機、不可裝活塞零件與切回車型由專屬測試驗證。原有 SC 354 組與既有車款回歸保留。

實際瀏覽器離線 Web Audio 64／64 通過：主 Worklet 與 callback 備援在 30,000→54,000 RPM 有不同且正確移動的轉子階次；後燃增強連續轟鳴、關機保留滑轉、停止與靜音為零。這些量測驗證訊號行為，不代表已與 J85 原機錄音逐頻校準。

正式建置成功。瀏覽器 320×568、390×844、667×375 與 1280×720 檢查啟動、乾／後燃推力、收油、關機滑轉、3D／剖面／特寫、慢動作及 AMT→噴射→車款切換；無水平溢出或 JavaScript 錯誤。手機尺寸是瀏覽器視窗驗證，實際裝置的音訊與手勢仍由使用者測試。
