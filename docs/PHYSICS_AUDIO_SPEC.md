# engine_sim — 物理、換檔、煞車、聲浪規格（Codex 必讀）

本文件是**規範，不是可驗證完成的物理模型**。所有模型採「由簡到真、逐項校驗」方式建立；不得把視覺效果冒充物理結果。單位一律明確：rad、rpm、m/s、Nm、kg·m²、秒；km/h 僅為 UI 顯示轉換。

## A. 唯一狀態來源（Single Source of Truth）

核心模擬狀態至少包括：`engineOn`、`engineRPM`、`crankAngle720`、`throttle`、`gear`、`shiftMode`、`brakeFront`、`brakeRear`、`wheelAngularVelocity`、`vehicleSpeed`、`clutchCoupling/Slip`、`engineTorque`、`drivetrainTorque`、`wheelTraction`、`overRevState`、`damageState`、`engineLoad`、`audioPhase`、`selectedBikeYearVariant`、`exhaustConfig`。不能讓畫面、音訊、3D 分別自行猜測 RPM。

使用固定時間步長更新物理狀態；音效要在音訊時間線細粒度排程並與引擎角度保持相位一致；3D 畫面可以插值渲染。切換分頁、低 FPS 不得導致一次補跑大量時間造成 RPM 突跳或音訊爆炸。模擬播放／暫停與音效暫停須有明確行為。

## B. 活塞/點火運動學

對理想同軸曲柄連桿，以曲軸旋轉角 θ、曲柄半徑 r = stroke/2、連桿中心距 l，活塞沿缸軸的參考位置可寫成：

`x(θ) = r·cos(θ) + sqrt(l² − r²·sin²(θ))`（相對曲軸中心之軸向位置，頂點/原點需一致定義）。

對實際有偏置的汽缸（例如 R3 某些公開資料記載之 offset cylinder），需要採用偏置曲柄連桿幾何，**不能將上述理想同軸式宣稱為原廠精確機構**。連桿長度、偏置距離若無來源，初期可以用帶標籤的近似值；必須可替換。

四行程完整週期為 720° 曲軸角；凸輪軸一般以曲軸角速度一半旋轉。進排氣門開閉應以可替換的正時曲線/事件驅動，未查到原廠開閉角時只能做示意。

已確認：**Yamaha R15** 單缸（四行程每 720° 一次燃燒事件）；**R3** 180° 並列雙缸，需實作 720° 週期內**180°/540° 不均等燃燒間隔**，並標記實際汽缸相位定義與點火順序。不可用「雙缸 = 每 360° 一次燃燒」替代。

**R15 VVA**：有可變汽門機構，但未取得確切切換點／凸輪揚程曲線前，僅做「低轉/高轉模式，切換點待驗證」；若動態控制要用暫定切換轉速，務必在工程模式標成可配置的近似參數。

## C. 動力／速度／制動

核心關係（耦合完全且沒有離合滑差的近似情況）：

- 後輪轉速 `wheelRPM = (vehicleSpeed_mps / (2π·effectiveRollingRadius_m)) × 60`。
- 總減速比 `G_total = primaryRatio × gearRatio[currentGear] × finalDriveRatio`。
- 引擎受車輪反拖的**估計匹配轉速** `matchedEngineRPM = abs(wheelRPM × G_total)`。
- 運動方程應分別處理引擎轉動慣量、車體質量、輪系慣量、摩擦阻力、離合器滑差與車輪抓地；不可在所有情況下把引擎 RPM 硬設成 matchedEngineRPM。

引擎淨扭矩 = 燃燒輸出扭矩 − 機械摩擦 − 泵氣損失 − 附件負載 − 傳動反作用力。油門釋放、車速仍高且有檔位耦合時，應自然形成引擎煞車；煞車產生輪胎減速，並沿齒輪與虛擬離合器耦合反推引擎轉速。不能用「按剎車 → RPM 線性下降 500」的假演算法。

車速變化需反映驅動輪扭矩、煞車扭矩、空阻、滾阻、坡度（可留為後期）及抓地限制。若輪胎抓地不足，需區分 **wheel speed ≠ vehicle speed** 的滑移狀態。初期若不做完整輪胎模型，必須明示簡化而非強行一致。

## D. 變速箱、離合器與控制

### 1. 顯示與操作

- 按使用者要求提供 **`1 – N – 2 – 3 – 4 – 5 – 6`** 六速序列，UI 以 `+`、`−` 撥片，不要求操作實體離合器。
- **N 是空檔，不是齒比**。從一檔到二檔的正常完整換檔不能強制卡在 N；從一檔輕撥進空檔需獨立邏輯、低速或明確操作條件（具體以使用者體驗與車型設計決定）。
- 初期設計**虛擬離合器／換檔扭矩切斷／再接合**：隱藏於物理核心，使用者不需操作，但操作結果仍需物理連續。
- `MT` 模式：駕駛可連續下達退檔；允許超轉情況，不得默默加「防超轉保護」而讓錯誤換檔永遠無效。
- `AT` 模式：網站自創的**虛擬自動換檔輔助**（不是原廠 R15/R3 變速箱）；利用合宜的檔位策略、扭矩需求與遲滯防頻繁升降檔，在執行**退檔前先預測接合後 RPM**，危險則拒絕或延遲退檔。
- MT 是否自動退檔補油與虛擬滑動離合控制要做成**可配置的模式或車型差異**，不能未查證就宣稱每款原車都有雙向快排。

### 2. 換檔狀態機與聲音瞬態

建議狀態：`IDLE → REQUESTED → TORQUE_UNLOAD → DISENGAGE/PARTIAL_SLIP → RATIO_TRANSITION → REENGAGE → SETTLE → IDLE`；失敗換檔可回到前一合法檔。每個階段有相應扭矩傳遞、引擎加減速與音訊變化。

- **升檔**：扭矩切斷（短時間燃燒動力減少）、齒比下降、車速/引擎轉速耦合、重新施力；不可做成「RPM 固定瞬降一個常數再播放咔一聲」。
- **手動降檔**：低檔齒比提高，接合目標 RPM 升高。若有退檔補油，合成短促 blip，但需由需求的轉速匹配決定長短及幅度；否則由後輪反拖引擎升轉，可能帶來引擎煞車及輪胎滑移。
- **自排降檔**：在加速需求增加或減速時可主動退檔，但先驗算預測匹配轉速，再決定補油/接合；不可在高速突然進一檔。
- **連續退檔**：輸入需排隊或按操作條件節流，**每次換檔都必須有實際經過的機械狀態和時間**，不能同一個 3D frame 當作已立即跳多檔。若短時間連退數檔，最後接合 RPM 超出安全值，必須能真實觸發超轉邏輯。

### 3. 強制超轉（money shift）

RPM 限制器**僅能切斷燃燒輸出**；若車速高、降進低檔、傳動耦合迫使引擎轉得更快，限制器無法從物理上保證不超轉。

區分：
1. **動力側超轉**：加油超過限轉門檻，限轉器限制燃燒動力。
2. **機械側超轉**：因低檔接合被後輪反拖至過高轉速，即使斷油也可能持續超出限制。

執行下列檢查：
- 預測 `matchedEngineRPM`，若超出已驗證的限轉門檻標示風險；
- 以滑動離合器（如來源支援）、離合器滑差、後輪抓地與傳動彈性決定**實際**達成的 RPM（未必每次一定破表）；
- 機械超轉持續時間/超限幅度記錄事件；可觸發「模擬機械損壞」或「後輪不穩」警示，但**引擎損壞的精確閾值如無實測不可標示為原廠數據**；
- 模擬可重置，不能把超轉變成鼓勵現實危險操駕的教學。

## E. 聲音系統（最高優先功能之一）

### 基礎原則

**任何轉速、換檔、退檔補油、煞車造成的聲音變化，都來自同一套狀態與事件。** 音效不可因 UI 點擊而單獨播放一段固定換檔特效，與引擎 RPM 無關。

音訊建議分層（可逐步實作）：
1. 燃燒/排氣脈衝：依汽缸數、720° 點火時序、相位排程產生。
2. 進氣：依油門開度、流量/負載、轉速變化。
3. 引擎機械：汽門、鏈條、齒輪、機械敲擊（需有合理的調變來源）。
4. 排氣系統：原廠/改裝排氣管頻譜與共鳴、消音器、排氣脈衝混合與衰減。
5. 傳動/換檔：卸載時的音量與音色變化、補油、接合瞬態、滑差和車速相關噪音。
6. **機械增壓專用層（H2 / H2R 階段才開啟）**：離心式增壓器高頻旋轉/齒輪傳動聲、增壓與旁通/進氣共鳴，隨實際壓縮機速比及負載變化；不能直接拿一般渦輪增壓音代替。

### R15 / R3 的必要差異

- **R15**：單缸、720° 燃燒週期，低轉與高轉 VVA 工況後期可讓進氣音色合理變化；初期若沒錄音，合成結果明示「示意音效」。
- **R3**：180° 並列雙缸對應非等距點火事件；不能用 R15 的單缸聲音加速兩倍或複製相同聲浪。兩車各自有專屬音訊設定與來源。

### 過渡與移動裝置

- **換檔聲音連續**：燃燒脈衝相位與音訊時間要連貫；卸載、轉速改變、恢復供油平滑過渡，避免接縫、喀喀的數位爆音。
- **煞車/降檔**：按下煞車不直接下調音訊音高；必須由負載和速度影響到引擎 RPM 再改變聲音。放掉油門時即使車速不變，也會有負載/音色變化。
- **原始樣本若僅單一 RPM**：不可單純 pitch shift 全轉速域並宣稱真實；最好建立多 RPM×油門×負載錄音的分層切換/交叉淡入、相位對齊與適當播放速率策略。
- 若做程序合成需控制混疊/削波；使用 limiter/壓縮器前確認最大音量安全，沒有使用者操作不得突然發出聲音。
- 手機瀏覽器有音訊自動播放限制，必須在使用者手勢後啟動或 resume AudioContext；偵測靜音/背景恢復失敗並提供重啟音訊按鈕。

### 改裝系統擴充設計

- `BikeEngineProfile` 與 `ExhaustProfile` 分離；同一顆引擎可換原廠、全段/尾段、db killer、進氣、ECU profile。
- 音源應具有 license、recorded/synthetic、RPM 工況、負載、距離、麥克風、位置、檔位、排氣版本、音質限制。
- 改裝排氣導致的動力差異**需要測功機/原廠或可信來源證據**；沒有證據只改音色，不亂加馬力。
- 不要未經測試宣稱聲音與真車「一模一樣」。

## F. 必須能通過的物理與音效測試（程式實作時）

1. 靜止 N 檔發動並加油，RPM 上升、輪速不應因離合器/傳動耦合而同步被驅動。
2. 一檔起步，在不提供離合 UI 的前提下由自動接合邏輯平滑起步，不可瞬間傳動衝擊到非物理速度。
3. 相同速度從 3 檔升到 4 檔後，若耦合完成，引擎 RPM 應依新齒比下降，而非無條件減同一固定數量。
4. 高速放油門，有檔位耦合時引擎煞車；逐步剎車減速時，輪速/匹配 RPM 下降，真實引擎 RPM 視離合滑差與怠速控制反應。
5. 高速從 6 檔連退到 3 檔：MT 在適當車速/參數下可產生被輪子反拖的機械超轉；**限制器不能硬封頂**。相反地，低速連退檔不應無理由觸發超轉。
6. AT 在同樣情境不應主動切入預測會超轉的低檔。
7. R15、R3 同 RPM 的燃燒事件時間序列不同；至少實作 R15 每 720° 一次、R3 180°/540° 事件差異。
8. 連續多次升/降檔，每次換檔過渡都與 RPM、齒比、輪速一致，不會重播一模一樣的轉速跌落和聲音片段。
9. 煞車時音效依 RPM 與負載自然調整，不能另播放「按下煞車音效」取代真實轉速變化。
10. 音訊開關／停止／再啟動／背景恢復不產生突然最大音量的尖銳瞬態；3D 與儀表持續讀同一狀態。

這些是**預期驗收**，不是宣稱現有網站已通過。實作完成後逐項記錄 PASS / FAIL / PENDING，並附重現方式。
