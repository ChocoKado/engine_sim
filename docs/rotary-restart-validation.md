# 轉子怠速與測試後再起步

檢查日期：2026-10-02。

## 本次改動

- RX-8 增加原廠 RENESIS／改裝 Brap 聲浪切換。原廠保留規律燃燒脈衝，Brap 在低轉、低負載呈現強弱段落；拉轉與加載後收斂。兩模式共用連續燃燒相位，不切斷整個音訊輸出。
- 怠速減少過長的排氣脈衝尾音及反射，移除轉子的虛構凸輪軸低頻純音。排氣管仍決定阻尼、音色與音量；音效設定不改引擎扭力。
- 實際載荷將曲軸停到 0 RPM 時，模型標記失速、停止燃燒，App 同步停止聲音、取消進行中的性能測試並顯示重新發動提示。啟動鍵依模型實際狀態決定動作，避免介面仍顯示運轉而第一下只是在關閉失速引擎。

## 使用者回報與已知邊界

使用者描述「完成加速測試，調整紅線與 ECU，再起步時轉速掉到 0 且無法踩油門」，車款可能是 Yamaha R1 CP4，傳動模式未確定。

已分別檢查 AT／AMT、完成／提前保存、紅線及 ECU 節奏／深度改動、直接煞停與回到起點、換檔中重設。這些標準操作目前沒有重現原回報。確定重現並修復的是另一個狀態不一致：外部負載使引擎真正失速後，仍保留點火／運轉旗標，且必須按兩次啟動才恢復。因此不能將此修復宣稱為已確認原回報的根因。

失速沒有以強制 RPM 下限、額外扭力或自動重新啟動隱藏；真正重啟仍需按啟動。改裝 Brap 為程序音效示意，不是原廠 RX-8 錄音，也沒有新增完整橋式埠動力模型。

## 驗證範圍

- `tests/performance-restart.test.js`：全部 20 款 × AT／AMT，跑完或保存性能測試後修改限轉設定並再次起步；另涵蓋完整測試、直接煞停與換檔途中重設。CP4 加測最低／最高紅線與硬切／逐缸 ECU 組合。
- `tests/engine-stall.test.js`：真正負載失速、保持油門不能自啟、明確啟動一次恢復、渦輪剩餘動能續轉、預設／手動停機狀態。
- `tests/ui-state.test.js`：真實失速同步聲音／按鈕／測試，按一次重新發動並驅動車輛；轉子專用控制項顯示與保留選擇。
- `tests/audio-browser.html`：實際離線 WebAudio 渲染兩種怠速 × 四支排氣管，檢查段落差異、全程切換、拉轉收斂、靜音及熄火。頁面有原廠／Brap 的 850 RPM 試聽及 WAV 下載，預設不播放。

數值、連續性與操作測試不能代替真車音色及手機音效的聆聽；整體結果見 [修復對照](repair-status.md)。未實作架構的擴充分期與原資料校正見 [引擎架構擴充選項](engine-expansion-options.md)。
