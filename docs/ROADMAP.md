# engine_sim — Codex 小批次開發路線

**原則：每次只做一個里程碑；5 小時額度有限，完成就停。** 對每一項工作先檢查現有程式和已完成事項，避免重做。

| 編號 | 主題 | 界線與成果 | 必要驗收 |
|---|---|---|---|
| M0 | 規格/儲存庫稽核 | 讀本包、檢查既有專案，不新增大量程式。確認已存在框架、需要補來源的欄位與風險 | 簡短摘要、標出下一步；禁止變成全站重構 |
| M1 | 可操作的手機網站骨架 | Next.js 如有則沿用；R15/R3 選擇器、手機 UI、RPM/檔位/車速儀表、撥片及油門煞車輸入狀態，資料與模擬 UI 分離 | 手機直/橫屏、控制按住/放開正確；未完成物理明示示意 |
| M2 | 共享物理核心（兩車） | 固定步長、油門、引擎 RPM/慣量、輪速/車速、引擎煞車、基本物理測試；各車型分配置 | 單元測試、煞車與油門有物理因果，不用固定 RPM 動畫 |
| M3 | MT/AT 與超轉 | 1-N-2-3-4-5-6、+/-、換檔狀態機、隱藏虛擬離合器、補油、滑動式離合簡化、AT 防危險降檔、MT 連續退檔超轉 | 高速退檔、引擎煞車、轉速限制器≠機械防超轉、AT 預測限制 |

| M5 | 3D 引擎運動 v1（兩車） | 可旋轉、剖面、正確曲柄連桿與 720° 循環；缺尺寸標近似；R15 VVA 先做機制框架 | 3D/儀表/聲音共用物理狀態；在手機降畫質可用 |
| M6 | 真實性驗證與精調 | 年式指定、齒比/輪胎/動力曲線補證據、損壞與滑差模型、音訊來源／對照流程 | 來源完備或明示缺失、可重現物理測試與真機測試 |
| M7 | GitHub/Vercel 正式流程 | README、CI、預覽網址、效能/載入、安全音量、部署指引 | build、preview、手機上線測試；無授權不聲稱已部署 |
| M8 | Yamaha 擴充 | 依序 R7→R6→R9→R1（允許因聲學需求調整順序），每款獨立參數、音訊、驗證 | CP2/三缸/crossplane 差異顯著且有來源 |
| M9 | Kawasaki 擴充 | ZX-25R→ZX-4R→ZX-6R 599/636→ZX-10R→ZX-14R | 599 與 636 分開版本資料；高轉四缸有個性 |

| M11 | 摩托車改裝音色 | 版本化車型基準、加消音塞、開放排氣與高流量進氣聲型；可信實測可補 ECU／扭矩資料 | 原有引擎、輪速、換檔與音訊時鐘維持連續，改裝音色的頻譜可區分 |

**遇到額度不足**：不要趕工亂寫。將尚未完成部分及重現步驟更新到 PROGRESS，停止工作；下一個視窗續做同一個里程碑。
